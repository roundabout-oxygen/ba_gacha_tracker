# ブルアカ リアルタイムガチャ集計 (BA Gacha Live Tracker) [v1.0.1]

『ブルーアーカイブ（ブルアカ）』のガチャをリアルタイムに引きながら、スプレッドシート（CSV/TSV）形式で手軽に入力・記録し、配信画面やダッシュボードで即座に集計できるWebアプリケーションです。

---

## 🌟 主な機能

### 1. 🎯 ブルアカ準拠のチャージ引継ぎ ＆ 自動リセット仕様
- **開始前チャージ引継**: 前回の募集から引き継いだチャージ数（0〜199）を初期設定可能。
- **100連目（チャージ100）**: ☆3生徒確定 ＆ 50%の確率でピックアップ生徒が排出される仮天井枠。
- **200連目（チャージ200）**: 100%ピックアップ生徒が排出される天井枠。
- **チャージ自動リセット**:
  - 通常引き（1〜99、101〜199連等）でも、100連目でも、200連目でも、**ピックアップ生徒（pick☑）を引いた時点でチャージは即座にリセットされ、次の引きからはチャージ 1 から再カウント**されます。
  - 10連入力シートの途中で pick にチェックを入れると、後続の行のチャージ数がリアルタイムに自動再計算されます！

### 2. 📋 添付2枚目を完全再現したスプレッドシート入力UI
- 「1連」ボタン / 「10連」ボタンからワンクリックで入力シートを展開。
- **列構成**:
  - `連番`: 1〜10（1連なら1）
  - `累計`: 通算のガチャ連数
  - `チャージ`: 現在のチャージ数（100連目は薄黄色 `#fff2cc`、200連目はゴールドでハイライト）
  - `生徒名`: キーボード手打ち可能。☆1・☆2は空欄でOK！
  - `pick`: ピックアップ生徒なら自動または手動チェック☑
  - `新`: 未所持の新規生徒なら自動または手動チェック☑
- **平仮名・カタカナ前方一致入力ガイド**:
  - 生徒名セルにフォーカスまたは文字入力すると、顔アイコン付きのサジェストポップアップが出現。
  - 「ここ」で「ココロ」、「みか」で「ミカ」、「ある」で「アル」など平仮名入力でも高速マッチング！
  - クリックまたはEnterで一発入力。
- **快適な操作ボタン**:
  - `← 戻る`: 入力を取り消して戻る
  - `✔ OK`: 入力を確定して集計ダッシュボードへ
  - `次の10連 →` (1連なら `次の1連 →`): 現在の引きを確定し、**そのまま即座に次の10連入力枠を開く**ため、ガチャ実況や配信中に超爆速で連続入力可能！

### 3. 📊 単一ガチャに最適化された集計ダッシュボード
- 3%通常募集と6%フェス募集を同時表示せず、**選択された確率（3%または6%）に一本化した見やすいUI**。
- **常時表示ステータスバー（最上部固定）**:
  - 総ガチャ回数 / 消費青輝石
  - ☆3実測確率（目標との過不足人数）
  - ピックアップ実測確率
  - 100連目50%枠勝率（勝/敗/勝率%）
  - 現在のチャージ進行バー（次の仮天井・天井まであと何連か）
- **★3 確率収束折れ線グラフ (Chart.js)**:
  - 公表確率基準線（3% or 6%）と実測☆3排出率の推移を1本ですっきり可視化。
- **排出☆3生徒図鑑**:
  - 獲得生徒の顔アイコン一覧（横並び）。
  - 枠色分け:
    - 🟡 **ゴールド枠**: ピックアップ生徒
    - 🔴 **レッド枠**: 新規獲得生徒
    - 🟢 **グリーン枠**: 100連目50%枠で獲得した生徒
    - ⚫ **ブラック枠**: 200連天井で獲得した生徒（「天井交換」バッジ）
    - ⚪ **グレー枠**: 通常すり抜け生徒
  - 重複獲得（被り）バッジ: 「2回目」「3回目」...
- **スプレッドシート連携 ＆ CSV保存**:
  - 「📋 スプレッドシート用コピー」ボタンで、GoogleスプレッドシートやExcelに一発で貼り付けられるTSVをコピー！
  - 「💾 CSV保存」でファイル書き出し。
  - 「↩ 直前を取り消す」で入力ミスを即時Undo。

### 4. 🖼️ 新規生徒アイコン仮登録機能（添付1枚目完全再現）
- ガチャ新実装時にWikiや図鑑にまだアイコンがない生徒に対応。
- 画像ファイル選択、ドラッグ＆ドロップ、または **Ctrl+V クリップボード画像貼り付け** に対応。
- **インタラクティブ・クロッパー（□と〇の切り抜きガイド）**:
  - 正方形の切り抜き枠（□）の内側に、円形（〇）のガイドライン。
  - 画像のドラッグ移動、スライダー/マウスホイールによる拡大・縮小、90度回転。
  - 添付1枚目のような「生徒カード形式プレビュー（角丸カード、丸アイコン、生徒名、交換/日付）」をリアルタイム表示！
  - 「切り抜いて仮登録する」で、丸型PNGアイコンとして保存。サジェストや図鑑ですぐに利用可能！

### 5. 📝 仮登録エディタ ＆ Wiki自動クリーンアップ ＆ GitHub共有
- **表記揺れの自動正規化 ＆ エディタ**:
  - 半角かっこ `()` は全角 `（）` に自動統一。
  - 仮登録エディタから生徒名の修正や不要な仮登録の削除が可能。
- **Wikiデータ同期＆自動クリーンアップ**:
  - Wiki公式データ（`student_icons.json`）が更新され、同名生徒の公式アイコンが追加された場合、仮登録側の該当生徒を自動検知して削除・正規データへと移行！
- **GitHub共有連携**:
  - 図鑑データとは別の独立フォルダ `data/temp_students/` および `data/custom_students.json` で管理。
  - GitHub Personal Access Token を登録すると、リポジトリ（`roundabout-oxygen/ba-gacha-live-tracker`）へ直接コミット＆プッシュして他の利用者とも共有可能！
  - JSONのエクスポート / インポートにも対応。

### 6. 🎥 配信（OBS）専用オーバーレイHUD
- ヘッダーの「🎥 配信UI」ボタンを押すと、OBSのブラウザソースとしてそのまま取り込める半透明HUDが表示されます。
- 総回数、☆3確率、PU確率、50%枠勝率、現在チャージをコンパクトに表示。

## 🚀 ご利用方法

### 起動方法
フォルダ内の `start.bat` をダブルクリックするだけで、自動的にローカルサーバーが起動し、ブラウザでアプリが開きます。

```bat
start.bat
```

## 📁 ディレクトリ構成

```text
ba-gacha-live-tracker/
├── data/
│   ├── student_icons.json      # Wiki公式の生徒アイコンURLマッピング (275+名)
│   ├── custom_students.json    # 新規生徒アイコン仮登録データ (独立共有)
│   └── temp_students/          # 仮登録画像やサンプル保存フォルダ
├── scripts/
│   └── fetch_icons.js          # Wikiから最新アイコンを取得するスクリプト
├── index.html                  # アプリケーションUI本体 (v1.0.1)
├── style.css                   # ブルアカ風スタイルシート & スプレッドシートUI
├── app.js                      # ガチャ進行、チャージ計算、クロッパー、統計ロジック
├── start.bat                   # ワンクリック起動バッチ
└── README.md                   # 本ドキュメント
```
